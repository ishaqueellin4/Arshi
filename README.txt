WATERCOLOR PHOTO ALBUM

1. Upload all files/folders to your GitHub repository.
2. Put your music file inside the music folder and keep its filename exactly: Eka DIn - Lofi _ একা দিন _ Fidaa _ Minar _ Arindom _ Prasen _ Happy Pills _ SVF Music(MP3_160K).mp3
3. Deploy the repository on Vercel (Framework Preset: Other; Build Command and Output Directory can be left blank).
4. To add a page, open script.js and add another object to albumPages:
   { image: "images/photo5.jpg", text: "তোমার ক্যাপশন" }
   Then upload photo5.jpg into the images folder.
5. Background music may require tapping the music button because browsers restrict autoplay.

The four supplied photos are included as photo1.jpg through photo4.jpg.
